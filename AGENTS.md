# AGENTS.md

C11 ncurses text editor. Single binary, no test framework, no CI.
`TODO.md` is ideas-only — never implement from it unasked. `Makefile` is the source of truth (README is user docs; no opencode.json).

## Build

- `make` → `build/sulf`. `make clean` wipes `build/` (gitignored — never commit it).
- Run as `build/sulf [file ...]` (one tab per file; `--help`/`-h`, `--version`/`-V`, unknown `-opt` errors out).
- Requires `libncurses-dev`; link flag is `-lncursesw` (wide ncurses — UTF-8 rendering needs it) (`Makefile` `LDLIBS`).
- `make` must be zero-warning (`-Wall -Wextra -std=c11 -D_POSIX_C_SOURCE=200809L`).
- New `.c` file: add to `Makefile` `OBJS` **and** a per-object header-dep line, else incremental builds go stale.

## Layout (`src/` + `include/`, `Buffer` content + `View` cursor in `editor.h`, tabs in `tabs.c`)

- `main.c`: `tabs_init → tabs_open_file (per CLI file) → editor_start_screen → editor_run → editor_end_screen → tabs_free`.
- `editor.c`: status line, `editor_clamp_cursor`, selection helpers. `tabs.c`: fixed 16-slot buffer table, active tab, tab-bar draw/hit-test, open-or-switch + pristine-reuse, close. `line.c`/`util.c`: line-buffer growth + UTF-8 cell helpers + `die`. `buffer.c`: open/save, EOL detection/preservation. `edit.c`: mutations + cursor moves. `view.c`: scroll/gutter/draw + tab strip (row 0; text viewport is rows 1..`LINES-3`). `input.c`: keys + prompts + `editor_run` loop (clamp + `editor_scroll` + draw per frame, incl. palette/explorer modal routing). `screen.c`: locale/ncurses/termios init. `complete.c` / `highlight.c` / `mouse.c` / `undo.c` / `search.c` / `palette.c` / `explorer.c` / `clipboard.c` / `focus.c` / `git.c`: features (per-buffer state lives in `Buffer`, one history/cache per tab; palette/explorer/focus use static state in their own `.c`; git hunks live in `Buffer.git`).
- Style (enforced): tabs, Allman braces, guard clauses, `NULL` uppercase.

## Invariants agents commonly break

- Tabs are stored as literal `\t` bytes and never converted to/from spaces on load, save, or edit (`TAB_WIDTH 4` is display-only: tab stops at every 4th column from line start). Buffer is bytes, not cells: `cx`/`want_cx`/`col_off`/selection anchors are byte indices always snapped to char starts (`editor_clamp_cursor` + char motions/deletes); screen columns come from `line.c` tab-aware width helpers, never byte counts. `want_cx` stays byte-based. `screen.c` sets locale (`C.UTF-8`/`C.utf8` fallback); completion words stay ASCII-only by construction (high bytes are non-word). Unindent strips one leading tab or, for legacy space-indented lines, up to 4 spaces.
- EOL: `EolKind` + `trailing_nl` round-trip on save (`MIXED` saves as LF, then resets to LF).
- Cursor: `want_cx` goal column; roam below EOF is bounded by `editor_max_cy()` (`num_lines + view_rows - 2`), typing there is ignored via `NULL` guards, `col_off` is preserved on virtual rows. Text viewport starts at row 1 (`VIEW_TOP`) below the tab strip; view_rows = `LINES - 3`.
- Tabs (`src/tabs.c`, fixed 16 slots, no malloc): `sulf [file ...]` opens one tab per file; tabs share one `View` (cursor/selection/scroll do not follow tab switches — switching clears selection). Explorer `Enter` and palette `Open File...` reuse the pristine current tab, else open-or-switch. `Ctrl-]`/`Ctrl-^` + palette Next/Previous/Close Buffer + tab-bar click switch; `Ctrl-Q` prompts per dirty buffer (`y` saves incl. Save-as sub-prompt / `n` discards / `Esc` cancels quit). Close refuses dirty tabs (`Unsaved changes`); closing the last tab resets it to fresh unnamed. Focus-out auto-saves every dirty named buffer. Per-buffer undo/highlight/search/complete state dies with the tab; tab switches clear selection, reset completion, and deactivate search (query kept). Executable truth for tab switching is `input.c` (`Ctrl-]` next / `Ctrl-^` prev) — `README.md` and the `main.c` usage line saying `Ctrl-[` are stale docs.
- Explorer (`src/explorer.c`, static state, no malloc): `F2` opens rooted at the current file's dir (`.` if unnamed), `F2`/`Esc` closes; `Ctrl-P`/`F1` while open swaps to the palette and vice versa. Case-insensitive subsequence filter; `Up`/`Ctrl-P` + `Down`/`Ctrl-N` wrap, `Enter` drills into dirs or opens files via `tabs_open_file`, `Backspace`/`Ctrl-H` edits the query. Opening a file with a dirty current buffer runs the quit-prompt first (cancel keeps the explorer open). Mouse click dismisses, resize keeps state; open/reset clear completion and deactivate search (query kept).
- Enter: new line inherits the split head line's leading spaces (capped at `cx`); cursor lands after the indent.
- Past-EOF rows draw a bare `ACS_VLINE` separator; gutter numbers are absolute, min width 2.
- Quit: `Ctrl-Q` prompts `y`/`n`/`Esc` per dirty buffer (`Ctrl-X` is cut, not quit); `Ctrl-S` saves (prompts filename if unnamed).
- Clipboard (`src/clipboard.c`, static state, fixed 8KB buffer, no malloc): `Ctrl-C`/`Ctrl-X`/`Ctrl-V` + matching palette actions. Copy needs a non-empty selection (`No selection` otherwise), never touches the buffer (no undo/dirty), keeps the selection. Cut = copy + delete (single `UNDO_OTHER` unit), paste replaces the selection, lands the cursor at the end of the insert, splits/joins lines on embedded newlines, and is a no-op with `Cannot paste here` on virtual rows below EOF. Cut/paste deactivate search (query kept). Truncation reports `Clipboard truncated`, never silently.
- `screen.c` disables termios `IXON`/`IXOFF` so `Ctrl-S`/`Ctrl-Q` reach the app — don't remove. `raw()` passes `Ctrl-C` through (no SIGINT), so it is a safe binding.

## Feature contracts

- Complete (`COMPLETE_MIN_PREFIX 2`, fixed 32×64 tables, no malloc): auto-popup after 2 word chars + `Ctrl-Space` force; `Tab`/`Enter` accept, `Esc` cancels; case-sensitive, frequency then `strcmp` A-Z. Accept clears selection, deactivates search, and appends a trailing space (skipped when one already follows).
- Highlight: C (`.c`/`.h`) + Markdown (`.md`), default-background palette, per-line cache + full rescan on dirty flag. C tracks `/* */` state, MD tracks ```` ``` ````/`~~~` fence state; MD reuses the C palette (headings keyword, code string, bold number, italic preproc, quote comment, lists/rules preproc, link text keyword + URL string).
- Mouse: click-to-move on text + wheel scroll (±3 rows, roams below EOF like Arrow Down bounded by `editor_max_cy()`) + map-column jump (empty buckets ignored) + tab-bar click switches tabs; silent-off fallback when terminal lacks support. Never touches `sel_active` (no drag/release: `REPORT_MOUSE_POSITION`/`BUTTON1_RELEASED` off). Text clicks clear selection, reset completion, deactivate search (query kept).
- Map: always-visible right edge (`editor_map_width()` = 4: 3 content + `ACS_VLINE`; 0 when it would leave <1 text col, `view_cols` already narrowed). Buckets via `editor_map_bucket_start()` — 1:1 top-packed when the file fits, else floor-proportional. Per-column coverage of the longest line in the bucket (each cell samples one horizontal third of `view_cols`; last cell also covers overflow past `view_cols`). Tint is dominant non-`NORMAL` class of that line via `highlight_attr | A_REVERSE` (plain when unhighlighted/colorless). Viewport wash is `A_REVERSE` (`+A_BOLD` when covered); cursor bucket adds `A_UNDERLINE`.
- Select: `sel_active`/`sel_ax`/`sel_ay` anchor, active end is `cx`/`cy`, end-exclusive. Backspace/Del delete the range (multi-line joins head+tail, never drops below 1 line); typing/`Enter` replace it; `Tab` block-indents touched lines (`ex==0` excludes the last line) and shifts the selection. Only plain moves, mouse clicks, and completion-accept clear; both draw paths split runs with `A_REVERSE`.
- Search (`src/search.c`, static query + active flag, per-buffer fixed 512-match table, no malloc): `Ctrl-F` sticky find; `n`/`Enter` next, `N` prev (wrap), `Esc` cancels, empty query reuses last; case-sensitive `strstr`. Nav keys/mouse-wheel/resize preserve; any edit/mouse-click/completion-accept deactivates (query kept). Other matches `A_BOLD`, current `A_REVERSE` in both draw paths via `search_cover()` (selection wins ties); jumps set `cx`/`cy`+`want_cx` and rely on per-frame `editor_scroll()`; no undo interaction.
- Palette (`src/palette.c`, static state, fixed 64-char query + 20-entry table, no malloc): `Ctrl-P`/`F1` opener (`F1` survives muxes claiming `Ctrl-P`; both share one branch after the completion block). Case-insensitive subsequence filter, stable table order; `Up`/`Ctrl-P` + `Down`/`Ctrl-N` wrap, `Enter` runs, `Esc` cancels. Dispatches only existing actions (save/save-as/quit/open-file/find family/undo/redo/indent/delete-selection/unindent/clear-selection/copy/cut/paste/force-complete/next-buffer/prev-buffer/close-buffer). `Enter` snapshots the id then resets before dispatch (getnstr sub-prompts take over input); Quit propagates `editor_request_quit()` as the return. Active branch sits after focus, before search — mouse clicks dismiss-then-fall-through, resize keeps state; open/run reset completion and deactivate search (query kept). Fixed 40-col centered modal at row 1 drawn after `complete_draw()` (`A_REVERSE` selection; long queries truncate on display only). Rows render `icon + space + name` (`PaletteItem.icon`, static UTF-8-byte escapes so the source stays ASCII; each must stay 1 cell per `utf8_width_n` and clear of the wide ranges in `line.c`; display-only, never matched by the filter). Background dims via `palette_dim_background()` post-pass (`mvwinch` + `A_DIM` on every cell outside `palette_box()` — no `view.c` changes); `editor_run` parks the cursor in the query row. No undo interaction.
- Git (`src/git.c`, no malloc in state): `git diff -U0 HEAD -- file` parsed to a per-buffer capped 512-hunk table (`GIT_MAX_HUNKS`; over cap switches markers off, never partial). Refresh only on open/save/tab-switch/focus-in via epoch clock (`git_invalidate` bumps, `git_refresh` skips when current) — never in the draw path; `git_marker()` is the only draw-path call (pure lookup). Tints the existing gutter `ACS_VLINE` separator (green added / yellow modified / red deleted via `highlight_git_attr`, plain when colorless) so gutter width, mouse mapping, and minimap are untouched. Silent-off for unnamed/untracked/non-repo/missing-git (exit status distinguishes clean from no-repo; stderr to `/dev/null`, `--no-pager --no-ext-diff`, `GIT_OPTIONAL_LOCKS=0`, `git -C dir` so cwd never changes, single-quoted paths). While dirty shows last-saved markers; deletions at file top clamp to row 0.
- Focus (`src/focus.c`, static, no malloc): xterm tracking via raw `ESC[?1004h`/`l` (no terminfo cap exists) + `define_key("\033[I"/"\033[O", 1001/1002)` so ncurses decodes — never parse `ESC [ O` manually or `[O` leaks in as text. Focus-out saves only when dirty+named (`Auto-saved`, failures status-only, dirty kept); unnamed buffers skipped. `editor_end_screen()` (shutdown-then-`endwin`) replaces both bare `endwin()` calls (`main.c`, `die()`) or `[O` sprays into the shell after quit.
- Keys: ncurses has **no** `KEY_SUP`/`KEY_SDOWN` — Shift+Up/Down arrive via `kri`/`kind` as `KEY_SR`/`KEY_SF`; Shift+arrows/Home/End are `KEY_SLEFT`/`SRIGHT`/`SHOME`/`SSEND`, Shift+PgUp/PgDn are `KEY_SPREVIOUS`/`KEY_SNEXT` (`Ctrl-A`/`Ctrl-E` also Home/End). `Ctrl-]`/`Ctrl-^` switch buffer tabs. Shift+Tab is `KEY_BTAB` → unindent (block over selection, else current line); there is deliberately **no** Ctrl+Tab binding (plain xterm sends bare `0x09`).
- Page: `KEY_PPAGE`/`KEY_NPAGE` move exactly `LINES-3` rows, clamped to `editor_max_cy()`; `row_off` follows via per-frame `editor_scroll()` in `editor_run` (not inside `editor_move_page`).
- Undo: `Ctrl-Z`/`Ctrl-Y`; per-buffer full snapshots (content + cursor + selection + `dirty`) capped at 64, any new edit clears redo; consecutive char inserts/backspaces coalesce via `undo_begin`/`undo_end`; unindent pushes only when it actually strips. Capture frees the target slot first (undo-then-edit overwrites must not leak); eviction NULLs the memmove-duplicated top slot before capture — it aliases the shifted entry, freeing it is use-after-free.

## Verification (headless pty, no fixtures)

- Run with `TERM=xterm` under `pty.fork()`; wait for the first full draw before driving keys (early pty writes are swallowed — gate on >500 bytes, pace keys ~0.5s); then `Ctrl-Q` (+`n` if dirty) to exit.
- Mouse input must be SGR-1006: `\x1b[<btn;x;yM`, 1-based (`0`=press, `64`/`65`=wheel); release is lowercase-`m`-terminated (`\x1b[<3;x;ym`).
- ncurses sends delta frames (`\x1b[nS`/`\x1b[nT` scrolls, single-cell status updates): assert on **single-frame drains** or **last match** of `\x1b[r;cH` / `\x1b[nG` — never byte counts or full-status regexes over accumulated output.
- Keep throwaway verify scripts in `/tmp`, not the repo.
